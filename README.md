# Python Junior Mock

Отдельная программа для Windows: голосовое тренировочное интервью на русском для Junior Python Developer (ориентир — Яндекс). **Неофициальная симуляция**, а не собеседование от Яндекса.

Виртуальный интервьюер задаёт 5, 8 или 10 основных вопросов, слушает ответы, может уточнять и после завершения выдаёт оценку по расшифровке. На экране портрет собеседника. Голосовой движок — GPT-Live-1, оценка — GPT-6 Luna через OpenAI API.

## Как скачать установщик

1. Откройте вкладку **Actions → Build Windows installer** и дождитесь зелёной сборки.
2. Откройте сборку → **Artifacts → Python-Junior-Mock-Windows** и скачайте ZIP.
3. Распакуйте ZIP и запустите `Python-Junior-Mock-Setup-1.0.1.exe`.

GitHub → Code → Download ZIP скачивает **исходники**, а не установщик. Windows может предупредить о неподписанном издателе.

## Первый запуск

Разрешите доступ к микрофону в Windows. Нужен API-ключ проекта [OpenAI Platform](https://platform.openai.com/api-keys) с доступом к `gpt-live-1` и `gpt-6-luna`. Вставьте ключ в программе, выберите количество вопросов и нажмите «Начать интервью». Лучше использовать наушники.

Ключ находится в памяти процесса и не записывается на диск. Аудио/расшифровка передаются OpenAI для голосового диалога и оценки. Это отдельные платные API-запросы; подписка ChatGPT Plus не покрывает их.

## Для разработчика

```sh
npm install --no-audit --no-fund
npm test
npm start
npm run dist
```

Electron и electron-builder собирают Windows NSIS-установщик через GitHub Actions. Для сборки на Windows понадобится Node.js 22+.

## Ограничения

- Тесты без API-ключа проверяют локальную логику, но не доказывают работу живого голосового диалога.
- Количество вопросов регулируется инструкцией модели; строгое соответствие 5/8/10 в живой речи не гарантируется.
- Портрет статический; не видеоаватар.
- Вопросы не заявлены как подлинные вопросы конкретного рекрутера Яндекса.
- Данные беседы не сохраняются в локальную историю, а оценка зависит от точности расшифровки.

Документация API: [GPT-Live WebRTC](https://developers.openai.com/api/docs/guides/voice-webrtc?api=live) · [Live sessions](https://developers.openai.com/api/docs/guides/live-conversations) · [Delegation](https://developers.openai.com/api/docs/guides/live-delegation).
